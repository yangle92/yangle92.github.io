# 欢迎来到我的博客

经过重新设计，个人主页已经上线了：**https://yangle92.github.io/**

首页由三块组成——**在线应用**、**博客文章**、**技术笔记索引**。其中「博客文章」区块是自动的：
只要把写好 Markdown 文件放进本机的 `BLog` 文件夹，运行一次同步脚本，文章就会出现在首页。

## 怎么发一篇新文章

第一步，在 `C:\Users\yangle\Desktop\BLog` 里新建一个 `.md` 文件，随便起名字。
第二步，在项目目录下运行：

```bash
python sync-to-github.py
```

大约一两分钟后，文章就会出现在 `https://yangle92.github.io/` 的「博客文章」区块里。

## 文章头部的元信息

在文件最上方写一段 `---` 包起来的内容，可以精确控制文章的标题、日期、标签和摘要：

```
---
title: 文章标题
date: 2026-09-19
tags: [运维, Linux]
summary: 显示在首页卡片上的一句话摘要
---
```

这几项**全都是可选的**。不写也能正常发布，系统会这样兜底：

| 字段 | 不写时的取值规则 |
| --- | --- |
| 标题 | 取正文第一个 `#` 标题；再没有就用文件名 |
| 日期 | 取文件的修改时间 |
| 标签 | 取文件所在的**子文件夹名** |
| 摘要 | 自动截取正文第一段 |

## 用文件夹做分类

这是最省事的一招：在 `BLog` 里建子文件夹，文件夹名会自动变成文章的分类标签。

```
BLog/
├── 欢迎来到我的博客.md        →  标签：随笔
├── 运维/
│   └── Linux 常用命令.md      →  标签：运维
├── 数据库/
│   └── MySQL 索引笔记.md      →  标签：数据库
└── images/                    →  图片资源，不会当成文章
    └── 截图.png
```

首页顶部会自动出现「全部 / 运维 / 数据库 …」这样的标签筛选按钮，点一下就能过滤。

> 图片也可以直接放在 BLog 里，用相对路径引用即可（例如 `![](images/截图.png)`），
> 同步时会把整个文件夹一起镜像过去，相对路径不会失效。

## 支持的 Markdown 语法

首页内置了一个轻量的 Markdown 渲染器，常用的语法都支持：

- **标题** `#` ~ `######`
- **粗体** `**粗体**`、*斜体* `*斜体*`、~~删除线~~ `~~删除线~~`
- `行内代码` 与围栏代码块（可指定语言）
- [链接](https://gitee.com/yangle92)、图片、分隔线
- 有序 / 无序列表（支持嵌套）、引用块、表格

代码块示例：

```python
def greet(name):
    print(f"Hello, {name}!")
```
