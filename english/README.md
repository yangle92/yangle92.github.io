# 快乐英语乐园 · 小学英语学习系统

面向小学三到六年级的英语学习 Web 应用，纯前端架构，打开浏览器即用。

## 在线访问

| 站点 | 地址 |
| --- | --- |
| 🏠 个人主页（含博客） | **https://yangle92.github.io/** |
| 🎈 英语应用 | **https://yangle92.github.io/english/** |

> 个人主页由本仓库的 `homepage/` 目录构建，博客文章来自本机的 `BLog` 文件夹（见下方「博客同步」）。

## 主要功能

| 模块 | 说明 |
| --- | --- |
| 单词学习 | 分单元词汇表，点击即可发音（系统语音 + 在线发音双引擎） |
| 语法讲解 | 小学阶段常用语法点归纳整理 |
| 趣味练习 | 单词拼写、选择题等互动练习 |
| 学习进度 | 星星数、已学单词、练习次数统计 |
| 登录认证 | 账号隔离，每个账号独立保存自己的学习进度 |
| 后台管理 | 管理员可维护账号、单词、语法与题库 |

## 本地运行

**方式一：直接打开**

双击 `index.html` 即可使用（语音功能需要浏览器支持）。

**方式二：启动本地服务器（推荐）**

```bash
python server.py
```

默认监听 `8000` 端口，同一局域网内的手机 / 平板可通过
`http://本机IP:8000` 访问，账号与学习进度由服务端统一保存、多设备共享。

Windows 用户可直接双击 `启动服务器.bat`。

## 博客同步

个人主页的「博客文章」区块会自动读取本机 `C:\Users\yangle\Desktop\BLog` 文件夹：

1. 在该文件夹里新建 `.md` 文件（可建子文件夹，文件夹名会自动成为标签）
2. 双击 `发布到GitHub.bat`（或执行 `python sync-to-github.py`）

1~2 分钟后文章自动出现在主页上。文件头部可选写 `title` / `date` / `tags` / `summary`，
不写则自动从正文标题、文件修改时间、子文件夹名推断。

## 部署说明

本站点**纯静态**，已发布到 GitHub Pages：

- 线上地址：<https://yangle92.github.io/english/>
- 更新方式：在本目录执行 `python sync-to-github.py`，自动同步并推送

在纯静态环境下 `server.py` 的后端接口不可用，前端会自动回退到浏览器本地存储，
此时账号与学习进度保存在各自设备的浏览器中，**不跨设备同步**。
若需要多设备共享进度，请在本机用 `启动服务器.bat` 运行带 `server.py` 的版本。
