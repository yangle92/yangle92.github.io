## 一、应用简介

### 1.1 这是什么

「快乐英语乐园」是一个面向小学生的英语学习网站，覆盖**单词、语法、练习**三大板块。所有数据保存在浏览器本地（localStorage），不需要账号、不需要联网注册，打开即用。

### 1.2 内容规模

| 板块 | 数量 | 说明 |
|------|------|------|
| 单词库 | **310 个单词 / 31 个分类** | 动物、水果、颜色、数字、家庭、职业、动词过去式、反义词等 |
| 语法专题 | **21 个专题** | 从 be 动词、a/an 到比较级、感叹句，每个专题含讲解表格 + 记忆口诀 + 例句 |
| 练习题 | **186 道题** | 单词选择题、各语法专题配套题、综合混合模式 |
| 单词拼写 | **253 个可拼单词** | 看图（emoji）+ 中文 + 音标，字母块拼单词 |

### 1.3 功能特性

- **单词学习**：翻转卡片式学习，点卡片翻面看中文和例句，点 🔊 听发音
- **语法学习**：每个专题含规则表格、记忆口诀、可发音例句，底部有"🎯 做本节练习"直达按钮
- **趣味练习**：单词小测验、🔤 单词拼写、21 个语法专题练习、综合混合模式
- **单词拼写**：支持鼠标点字母块和键盘直接输入，含 💡提示、🧹清空、退格删除
- **语音朗读**：双引擎（系统语音 + 在线真人发音多线路池），自动故障转移
- **激励体系**：星星奖励、学习进度统计、连续学习打卡
- **数据持久化**：星级、已学单词、练习成绩全部存在浏览器本地，关掉再开不丢失

### 1.4 文件结构

```
english-study/                     ← 项目根目录
├── index.html                     ← 入口跳转页（自动跳转到 app.html）
├── app.html                       ← 主页面（HTML + CSS，约 24KB）
├── 启动服务器.bat                  ← 一键启动脚本（重启电脑后双击即可）
├── 安装英文语音包.bat              ← Windows 补装英文系统语音（可选）
├── server.py                      ← 本地服务器：静态服务 + 账号/进度持久化 API
├── sync-to-github.py              ← 一键同步到 GitHub Pages（见 3.8 节）
├── README.md                      ← 项目说明
├── data/                          ← ⭐ 持久化数据目录（账号与学习进度）
│   ├── users.json                 ←    账号与密码哈希（重启服务不丢失）
│   └── progress.json              ←    各账号学习进度
├── 使用与运维手册.md               ← 本文档
└── js/
    ├── sync.js                    ← 服务端同步模块（与服务器双向同步）
    ├── data-words.js              ← 单词数据（310 词 / 31 分类，约 52KB）
    ├── data-grammar.js            ← 语法数据（21 专题，约 43KB）
    ├── data-quiz.js               ← 题库数据（186 题，约 32KB）
    ├── speech.js                  ← 语音朗读模块（双引擎 + 多线路池）
    ├── auth.js                    ← 登录认证模块（登录/登出/密码哈希）
    ├── admin.js                   ← 后台管理模块（用户/内容/备份，仅管理员可见）
    └── app.js                     ← 页面逻辑（渲染、练习、拼写、存储）
```

> ⚠️ `js` 文件夹必须和主 HTML 在同一目录，不能单独移动 HTML 文件。

## 二、使用指南（学生 / 家长）

### 2.1 打开方式

**方式 A：直接双击（单机使用）**
在资源管理器中双击 `小学英语学习系统.html`，用 Chrome/Edge 打开即可。

**方式 B：通过本地服务器（推荐，语音更稳定）**
见第三章"发布与运行"。

### 2.2 登录与注册

**首次打开网站会先进入登录界面**，登录成功后才能使用学习内容。

| 项目 | 说明 |
|------|------|
| 首次使用 | 登录页已**禁用自助注册**，需要账号请联系管理员添加（邮箱：821428991@qq.com）；管理员用 admin 登录后，在「后台管理」→「用户」页创建账号 |
| 管理员初始账号 | `admin` / `admin`（**仅记录在本文件中**，页面不再显示，登录后请尽快改密码） |
| 账号名规则 | 2–20 位，可用字母、数字、下划线或中文（不区分大小写，不可与他人重复） |
| 密码规则 | 至少 3 位 |
| 会话保持 | 登录状态保留 7 天，期间打开网站不用重复登录 |
| 退出登录 | 点右上角「👤 用户名 · 退出」按钮 |

**多账号互相独立**：每个账号的学习进度、星星、打卡记录**各自保存，互不影响**。家里有多个孩子时，可以各注册一个账号。首次登录时会自动继承本机的旧学习进度（不会清零）。

### 2.3 数据保存在哪（重要）

账号和学习进度**保存在服务器磁盘**的 `data/users.json`、`data/progress.json` 里，由 `server.py` 负责读写（用 `启动服务器.bat` 启动即是这个模式）。

| 好处 | 说明 |
|------|------|
| 重启服务不丢 | 关闭再打开服务器、重启电脑，账号和进度都在 |
| 换浏览器不丢 | 从 Chrome 换到 Edge，登录同一账号数据一致 |
| 手机电脑共享 | 用手机访问同一台服务器，登录同一账号，进度同步 |
| 改密码处处生效 | 在后台改了密码，所有设备立即用新密码登录 |

> ⚠️ **必须用 `启动服务器.bat`（即 `server.py`）启动才具备持久化能力**。
> 若直接双击 HTML（`file://`）或用纯静态服务器托管，程序会自动回退为「仅存本机浏览器」，
> 此时换浏览器/换设备就看不到了。判断方法：启动窗口里会显示
> `Mode: full server (accounts + progress saved in the data folder)`。

**备份很简单**：把 `data` 文件夹复制走即可（两个 JSON 文件）。恢复时覆盖回去，重启服务生效。

### 2.3 后台管理（仅管理员可见）

用管理员账号登录（初始 `admin`），顶部标签栏会多出「⚙️ 后台管理」；普通账号看不到这个标签。

| 功能页 | 能做什么 |
|--------|---------|
| **👥 用户管理** | 查看全部账号及各自的学习统计（星星/已学单词/练习次数/最近学习）；新增账号（可指定为管理员）、修改任意账号密码、设为/取消管理员、删除账号（会同时清除其学习进度） |
| **📚 单词维护** | 选择分类后可逐条修改单词的图标、英文、音标、中文、例句；支持添加/删除单词行、新建分类、重命名分类、删除整个分类；改完点「💾 保存修改」立即对所有账号生效 |
| **📝 语法维护** | 修改任一语法专题的简介、记忆口诀（一行一条）、例句（可增删改） |
| **🎯 题库维护** | 修改题目：题干、四个选项、用单选按钮指定正确答案、解析文字；可添加/删除题目 |
| **💾 数据备份** | 导出全部数据为 JSON（可选是否含账号）；导入 JSON 恢复；导出「单词库 JS」「题库 JS」文件用于固化修改；清空学习进度 / 清空内容修改 / 恢复出厂设置 |
| **📊 系统信息** | 展示分类数、单词总数、语法专题数、题目数、账号数、内容修改项数量、本地存储占用 |

**内容修改保存在哪？** 浏览器不能直接改写 `js` 文件，所以你的修改存在浏览器本地（键 `happyEnglishOverrides`），页面加载时自动覆盖生效。**要长期固化**：到「💾 数据备份」点「📄 导出单词库 JS」「📄 导出题库 JS」，下载后替换 `js/data-words.js`、`js/data-quiz.js` 即可（替换后记得点「清空内容修改」，避免重复覆盖）。

### 2.4 单词学习

1. 顶部标签栏点击「📚 单词学习」
2. 选择感兴趣的分类（动物、水果、颜色……）
3. 点击卡片翻面，查看中文意思和例句
4. 点 🔊 按钮听单词发音
5. 学过的单词卡片上会显示星星标记，进度自动保存

### 2.5 语法学习

1. 顶部标签栏点击「📖 语法课堂」
2. 选择语法专题（如"be 动词"、"名词复数"）
3. 阅读规则表格和记忆口诀
4. 点击例句旁的 🔊 听标准读音
5. 点「🎯 做本节练习」直接进入该专题的配套练习

### 2.6 趣味练习

1. 顶部标签栏点击「🎮 趣味练习」
2. 选择练习类型：
   - **📖 单词小测验**：看中文选英文 / 看英文选中文
   - **🔤 单词拼写**：看 emoji + 中文 + 音标，拼出单词
   - **各语法专题练习**：针对单个语法点的选择题
   - **🌟 综合模式**：单词 + 语法混合出题
3. 每轮 10 题，答对得星星，结束有成绩结算页

**单词拼写操作技巧：**
- 鼠标：点下方字母块填入，点已填的格子可退回字母
- 键盘：直接打字母输入，退格键 ⌫ 删除
- 卡住了：点 💡 提示一个字母（橙色标记），或 🧹 清空重拼
- 填满自动判分：拼对变绿弹跳，拼错显示正确拼写

### 2.7 学习统计

顶部标签栏「📊 学习统计」可查看：已学单词数、获得星星总数、连续学习打卡天数、各分类学习进度。

### 2.8 语音设置

右上角「🔊 语音设置」按钮打开面板，可查看：
- 当前使用的引擎（系统语音 / 在线发音）
- 系统英文音色数量
- 各在线发音线路的连通状态（绿=可用，红=不可用）

面板操作按钮：
- **🔄 检测线路**：重新探测所有在线发音线路
- **🔈 试听系统语音**：测试系统自带语音
- **🌐 试听在线发音**：测试在线真人发音
- **✨ 自动 / 仅系统 / 仅在线**：切换引擎模式（一般保持"自动"即可）

## 三、发布与运行（家长 / 运维）

### 3.1 为什么要用本地服务器

直接双击打开（`file://` 方式）功能完整，但：
- 部分浏览器对本地文件的安全限制更严格
- **无法被局域网内其他设备访问**（手机、平板用不了）

通过本地服务器发布后：
- 同一 WiFi 下的手机 / 平板都能访问，孩子用平板学习更方便
- 在线发音线路工作在标准 http 环境，兼容性最好

### 3.2 一键启动（推荐，重启电脑后双击即可）

项目根目录有一个 **`启动服务器.bat`**，双击它就会自动：

1. 找到电脑里可用的 Python（优先 WorkBuddy 自带版 → 系统 `python` → `py` 启动器）
2. 在 `0.0.0.0:8000` 启动服务器（最小化窗口运行）
3. 自动打开浏览器访问 http://localhost:8000/
4. 屏幕上打印出**手机/平板的访问地址**（自动识别局域网 IP）

启动后那个最小化的黑色窗口**不要关**（关了服务就停了）；本窗口 5 秒后自动关闭。

> ⚠️ **改动这个 bat 时注意编码**：它必须以 **ANSI(GBK)** 编码保存，且用 **CRLF** 换行。
> 若用记事本/VS Code 另存为 UTF-8，中文会变成乱码并报「'xxx' 不是内部或外部命令」。
> 用 VS Code 修改时：右下角编码选「GBK」或「Simplified Chinese (GBK)」，换行保持 CRLF。

> 想换端口：把 bat 拖到命令行后加端口号，例如 `启动服务器.bat 8888`。
> 没有 Python 时脚本会给出安装提示，装好 Python（记得勾选 Add to PATH）再双击即可。

### 3.3 手动启动（备用方案）

如果 bat 用不了，可以手动执行（服务器已绑定 `0.0.0.0:8000` 运行，命令如下）：

```bash
cd "C:\Users\yangle\Desktop\作业\english-study"
"C:\Users\yangle\.workbuddy\binaries\python\versions\3.13.12\python.exe" -m http.server 8000 --bind 0.0.0.0
```

> 简化版：系统里装了 Python 的话，在项目文件夹打开命令行执行 `python -m http.server 8000` 效果相同。

### 3.4 访问地址

| 场景 | 地址 |
|------|------|
| 本机访问 | http://localhost:8000/ |
| 局域网访问（手机/平板连同一 WiFi） | **http://192.168.3.17:8000/** |
| 局域网访问（备用网卡） | http://192.168.14.98:8000/ |

> 局域网 IP（192.168.3.17）来自 WiFi 网卡，**路由器重新分配后可能变化**。查询当前 IP：命令行执行 `ipconfig`，看"无线局域网适配器 WLAN"下的 IPv4 地址。

### 3.5 手机访问步骤

1. 手机连接与电脑**相同的 WiFi**
2. 手机浏览器输入 `http://192.168.3.17:8000`（用 bat 启动时，屏幕上会直接显示这个地址）
3. 若打不开 → 见 3.7 防火墙放行

### 3.6 修改端口 / 停止服务

- **换端口**：`启动服务器.bat 8888`（手动启动则改命令中的 `8000`），访问地址同步修改
- **停止服务**：关闭标题为「英语学习系统-服务器(勿关)」的最小化窗口；或在服务器窗口按 `Ctrl + C`
- **开机自启（可选）**：给 `启动服务器.bat` 建个快捷方式，放进启动文件夹（`Win+R` → `shell:startup`）

### 3.7 防火墙放行（手机访问不了时）

首次运行时 Windows 通常会弹窗询问，选择「允许」。若没弹窗或错过：

1. 打开「控制面板 → Windows Defender 防火墙 → 高级设置」
2. 「入站规则」→「新建规则」→「端口」
3. 选 TCP，特定端口填 `8000` → 允许连接 → 全部勾选 → 命名如 "EnglishStudy-8000"

### 3.8 发布到公网（已配置：GitHub Pages）

**当前线上地址：<https://yangle92.github.io/english/>**

本站已发布到 GitHub Pages，**不需要手动上传文件**，改完代码跑一个脚本就能更新。

| 方案 | 特点 |
|------|------|
| **GitHub Pages**（当前使用） | 免费、稳定、自带 HTTPS，挂在 `yangle92.github.io/english/` 下 |
| 内网穿透（花生壳、cpolar、frp） | 把本地 8000 端口映射到公网，数据始终在自己电脑上 |
| 静态托管（腾讯 EdgeOne Pages、CloudBase 等） | 上传 HTML + js 文件夹即可，免费额度通常够用 |
| 云服务器 + Nginx | 最正规，需要购买服务器 |

#### 更新线上站点（三步）

```bash
# 1. 改完代码后，先在 master 分支提交
git add -A
git commit -m "说明你改了什么"

# 2. 执行一键同步
python sync-to-github.py
```

脚本会自动完成：切到部署分支 → 用最新代码重建 `english/` 子目录 → 提交并推送到 GitHub → 切回 `master`。
推送成功后约 **1~2 分钟**，线上自动更新（无需任何网页操作）。

#### 为什么有两个分支（重要）

| 分支 | 用途 | 目录结构 |
|------|------|----------|
| `master` | 本地开发用，同时备份到 Gitee | 项目文件在**根目录**（双击 `index.html` 即可用） |
| `gh-main` | GitHub Pages 部署用 | 项目文件在 `english/` 子目录，根目录保留个人主页 `index.md` |

> ⚠️ **所有代码修改都在 `master` 分支上做**。不要直接在 `gh-main` 上改——下次同步会被 `master` 的内容整体覆盖。

#### 相关提醒

- 同步脚本依赖 GitHub 的 SSH 密钥（`~/.ssh/id_rsa`），本机已配置好，无需输入密码
- GitHub Pages 是**纯静态**托管，`server.py` 的后端接口不运行 → 账号与进度自动回退到浏览器本地存储，**不跨设备共享**（详见 2.3 节）
- 若手工上传到其它静态托管平台：把 `index.html`、`app.html` 和 `js` 文件夹整体上传即可

## 四、内容维护（加单词 / 改题目 / 加语法）

所有内容数据都在 `js` 文件夹下，**用任意文本编辑器（记事本、VS Code）打开直接改**，保存后刷新浏览器生效。

### 4.1 添加单词（`js/data-words.js`）

数据结构：

```js
const wordDatabase = {
  animals: {                        // 分类 key（英文，全局唯一）
    name: '动物',                    // 分类显示名
    emoji: '🐻',
    words: [
      { en: 'cat',  cn: '猫',  phonetic: '/kæt/',  emoji: '🐱' },
      // 添加新单词照抄这个格式，逗号隔开
    ]
  },
};
```

**新增单词三步**：找到对应分类 → 在 `words` 数组末尾加一行 → 保存刷新。注意上一行末尾要有逗号。

### 4.2 修改题目（`js/data-quiz.js`）

```js
const grammarQuiz = {
  be动词: [                              // 专题 id，须与 grammar.js 中一致
    { q: 'I ___ a student.', options: ['am', 'is', 'are', 'be'], answer: 0, explain: 'I 永远搭配 am。' },
    // q=题干, options=四个选项, answer=正确选项下标(0-3), explain=解析
  ],
};
```

### 4.3 新增语法专题（`js/data-grammar.js` + `js/data-quiz.js`）

1. 在 `grammarData` 数组中添加专题（含 `id / emoji / title / diff / intro / table / tips / examples` 字段）
2. 在 `grammarQuiz` 中添加同 `id` 的配套题（建议 8~10 题）
3. 保存刷新，练习菜单会自动出现新专题

### 4.4 数据备份与恢复

学习进度存在浏览器 localStorage，**按账号分开存储**：

| 数据 | 存储键 |
|------|--------|
| 账号与密码哈希 | `happyEnglishUsers` |
| 学习进度（某账号） | `happyEnglishDataV2:用户名` |
| 登录会话（7 天） | `happyEnglishSession` |

- **备份**：同一浏览器持续使用即可；换浏览器/清缓存前，可在统计页记录进度，或用浏览器导出 localStorage
- **清零重来**：浏览器按 `F12` → Application（应用）→ Local Storage → 删除对应账号的进度键
- **不同设备之间进度不互通**（各自独立），如需互通需二次开发后端账号系统

### 4.5 账号管理（登录认证）

账号数据存在浏览器 localStorage 的 `happyEnglishUsers` 键中，密码采用**加盐哈希**保存（优先 SHA-256，非明文；同时保存一份 FNV 兜底哈希）。

> 👍 **日常管理建议直接用后台**：管理员登录后到「⚙️ 后台管理 → 👥 用户管理」，可可视化地增删账号、改密码、设管理员、查看每个孩子的学习统计，不必敲命令。下面的控制台方法仅作应急（比如忘记管理员密码）。

> 💡 **为什么存两份哈希**：浏览器的 `crypto.subtle`（SHA-256）只在"安全上下文"可用，即 `https://` 或 `localhost`。当你用手机通过局域网 IP `http://192.168.3.17:8000` 访问时，SHA-256 不可用，程序会自动降级用 FNV 哈希校验。系统同时保存两种哈希，**保证同一个账号在本机、局域网、双击文件三种方式下都能登录**，不会出现"在电脑上注册了账号，手机上却登不进"的情况。

- **查看已注册账号**：控制台执行 `Object.keys(JSON.parse(localStorage.happyEnglishUsers))`
- **忘记密码 / 重置全部账号**：控制台执行
  `localStorage.removeItem('happyEnglishUsers'); location.reload();`
  执行后回到默认状态（admin/admin）
- **删除某个账号**：控制台执行
  ```js
  const u = JSON.parse(localStorage.happyEnglishUsers); delete u['要删的账号名'];
  localStorage.happyEnglishUsers = JSON.stringify(u); location.reload();
  ```
- **新增账号**：用 admin 登录后台管理 →「用户」页，填写账号名和密码即可创建（注册功能已对普通用户关闭）
- **修改默认管理员密码**：admin 登录后台管理 →「用户」页，对该账号执行「重置密码」；或删掉 admin 键后刷新页面，系统会自动重建 admin/admin

> ⚠️ 这是纯前端的本地账号系统，**没有服务端校验**，任何能打开这台电脑浏览器的人都可以用上面的方法重置账号。它的作用是区分不同孩子的学习进度、防止孩子误删数据，不是高等级安全防护。若需要真正的权限管理，需要二次开发后端服务。

## 五、语音问题排查（FAQ）

按以下顺序排查，绝大多数问题在第 1、2 步就能解决：

| 序号 | 现象 | 原因 | 解决办法 |
|------|------|------|---------|
| 1 | 在内置预览面板里点喇叭无反应 | 预览环境 CSP 安全策略拦截外部音频 | **不要用预览面板测语音**，用 localhost:8000 或双击 HTML 打开 |
| 2 | 语音设置面板显示"全部线路红色" | 电脑未联网，或网络拦截了发音接口 | 检查网络；换 WiFi/热点对比 |
| 3 | 系统语音无声（在线发音正常） | Windows 缺英文语音包 | 设置 → 时间和语言 → 语音 → 添加语音 → English (United States)，装好后点「语音设置」里的检测会自动切回 |
| 4 | 页面有声音但很小 | 标签页被静音或系统音量低 | 右键浏览器标签页查看是否静音；调大系统音量 |
| 5 | 偶发某次点击无声 | 线路瞬时故障 | 程序会自动换线路重试；再点一次即可 |

**语音架构说明**（供维护者了解）：
- 引擎 A：系统语音（Web Speech API），离线可用但依赖系统语音包
- 引擎 B：在线真人发音，线路池 3 条（有道词典美音 → 百度 gettts → 有道词典英音），单条失败自动切换，成功线路自动记忆
- 模式"自动"下：先试系统语音（1.3 秒无响应判定失败）→ 自动转在线；选择会记住，下次直接走在线不等待

## 七、技术信息（开发者参考）

- **技术栈**：原生 HTML5 + CSS3 + JavaScript（ES2017），零依赖、零构建
- **脚本加载**：经典 `<script src>`（非 ES module），`file://` 与 `http://` 均可运行
- **存储**：localStorage（学习进度键 `happyEnglishDataV2:用户名`；账号键 `happyEnglishUsers`；旧版键 `englishLearningData` 的进度会自动迁移）
- **认证**：`js/auth.js` —— 前端登录认证，密码 SHA-256 加盐哈希（`crypto.subtle`，不可用时 FNV-1a 四轮兜底），默认管理员 `admin/admin`，会话 7 天，登出按钮动态注入 header
- **单词进度 key**：`${分类key}:${单词下标}`（v3 之前带年级前缀，已做兼容迁移）
- **持久化架构**：`server.py`（Python 标准库，零依赖）提供静态服务 + `/api/users`、`/api/progress` 两组接口；账号与进度以 JSON 存于 `data/`，采用**原子写入**（临时文件 + `os.replace`）与 `threading.Lock` 防并发损坏；进度合并以 `updatedAt` 时间戳「新者胜出」避免旧设备覆盖新数据。前端 `js/sync.js` 负责检测与双向同步，**接口不可用时自动回退 localStorage**
- **接口一览**：`GET /api/health`（探测）、`GET|POST /api/users`（账号；值为 `null` 表示删除，admin 受保护，缺 `hash`/`salt` 的脏数据会被过滤）、`GET|POST /api/progress`（进度）
- **自动化测试**：`.workbuddy/test-spell.js`（拼写全流程）、`.workbuddy/test-speech.js` / `test-speech2.js`（语音引擎切换 27 项）、`.workbuddy/test-auth.js`（登录认证 39 项）、`.workbuddy/test-admin.js`（后台管理 41 项）、`.workbuddy/test-server-api.js`（服务端接口 26 项）、`.workbuddy/test-sync.js`（前后端同步 18 项），用 Node 运行：`node --check js/*.js` 校验语法
- **内容修改机制**：浏览器无法改写 js 文件，后台的内容修改存于 `happyEnglishOverrides`，加载时由 `Admin.applyOverrides()` 覆盖内存数据；「导出 JS」可把修改固化为 `data-words.js` / `data-quiz.js`
- **⚠️ 全局挂载约定**：`const` 声明不会自动成为 `window` 属性，`auth.js` / `admin.js` 末尾必须显式 `window.Auth = Auth;` / `window.Admin = Admin;`；否则 app.js 里的 `window.Auth` 判断全部失效（账号隔离与后台面板都会失灵）
- **浏览器兼容**：Chrome / Edge（推荐）、Firefox、Safari（含 iOS，已做手势解锁）
